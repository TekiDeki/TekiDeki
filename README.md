### 🎨 [Palette Studio](https://github.com/TekiDeki/Palette-Studio)

**Every color, measured. Nothing uploaded.**

Pull a palette out of a photograph with k-means, build harmonies and gradients from it, and measure WCAG 2.x contrast with a suggestion for the nearest accessible color. The same palette is then shown through the eight most common color vision deficiencies, using all 33 matrices published by Machado, Oliveira and Fernandes (2009) applied in linear RGB. Export as CSS variables, Tailwind, SCSS, JSON, SVG or PNG.

Palette from an image · seven harmonies · WCAG AA / AAA · 8 colour blindness simulations · CSS / Tailwind / SCSS / JSON / SVG / PNG · 4 languages · offline PWA

### 🌍 [Meeting Planner](https://github.com/TekiDeki/Meeting-Planner)

**The hour that works for every city in the room.**

Put the cities of a call side by side and see which hours fall inside working hours for all of them. Columns are cities, rows are hours in the first city, and every cell is coloured by whether it is working time, awake time or the middle of the night. Above the table a single sentence says when everyone is free, or how close you got when nobody is. It handles half hour and quarter hour zones exactly, and it ships no offset table at all: offsets come from the browser's own `Intl` data, so a country changing its daylight saving rules needs no update here. Pick any row to read that hour in every city and copy the message, or send the address of the page, because the cities and the day travel in the link.

Best-hour grid · daylight saving from the browser · half hour zones exact · shareable link · undo · 4 languages · offline PWA

## 🧠 How I build

The priorities behind my tools:

| Principle | What it means |
|---|---|
| 🪶 **Dependencies with purpose** | Use well-chosen libraries when they improve quality. Keep them lightweight, bundle locally where practical, and respect their licenses. |
| 📄 **Single file** | One `index.html` holds the whole app. CSS and JS included. |
| 🔒 **Privacy first** | Most tools process data locally. Online speech voices may send text to their provider; each tool explains its own privacy limits. No app backend or analytics. |
| 📦 **Offline by default** | Service workers & web app manifests. Install it like a native app. |
| 🚀 **Free to host** | GitHub Pages. No servers, no bills. |
| 📱 **Mobile-first** | Big touch targets, responsive layout, light & dark themes. |

> *"The best code is the code you don't have to ship."*
